# Accessible To-Do List

A simple and accessible to-do list application with a clean, modern interface.

## Features

- Add tasks with keyboard (Enter key) or mouse
- Clean, light blue color scheme
- Responsive design
- Accessible navigation
- Modern card-based task display

## How to Use

1. Open `hey.html` in your web browser
2. Type your task in the input field
3. Press Enter or click "Add Task" to add the task
4. Your tasks will appear in a clean, card-based list below

## Technologies Used

- HTML5
- CSS3
- JavaScript
